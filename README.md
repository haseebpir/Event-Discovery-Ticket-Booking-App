## ✨ Overview

**Evente** is a live event discovery and ticket booking app that helps people find concerts, shows, and local events nearby — and book a ticket in just a few taps. It also gives organizers a simple way to list events and sell tickets directly through the app.

---

## 💼 Why Users (and Clients) Love This

- 📍 **Discover Events Nearby** — Personalized event feed based on location and interests
- 🎟️ **Instant Ticket Booking** — Browse, select seats, and book — all in one smooth flow
- 📱 **Digital E-Tickets** — QR-code tickets for fast, contactless entry
- 💳 **Secure Payments** — Fast, encrypted checkout for every booking
- 🔔 **Smart Reminders** — Notifications before an event so tickets are never forgotten
- 🗺️ **Seat Selection & Venue Maps** — Visual seat maps for a clear, confident booking
- 📤 **Social Sharing** — Users can invite friends to events directly from the app
- ⭐ **Reviews & Ratings** — Build trust with feedback from past attendees
- 🧑‍💼 **Organizer Dashboard** — Event creators can list events and track ticket sales live
- 🌍 **Multi-Category Events** — Concerts, sports, comedy, workshops, and more in one app

---

## 🧱 How It Works

| Feature | Experience |
|---|---|
| **Discover** | Users browse a personalized feed of events happening near them |
| **Book Instantly** | Tickets are selected, paid for, and confirmed in seconds |
| **Enter with Ease** | A QR e-ticket makes entry fast and contactless |
| **Stay Reminded** | Notifications keep upcoming events top of mind |
| **List & Sell** | Organizers manage their own events and track sales in real time |

---

## 🛠️ Tech Stack (Under the Hood)

**Mobile App:** React Native (single codebase for iOS & Android)
**Backend:** Node.js, TypeScript powering bookings, payments, and event data
**Cloud Infrastructure:** AWS for secure, scalable, always-available hosting
**Integrations:** Payment gateways, maps, and push notification services

This stack keeps discovery and booking **fast, smooth, and reliable**, even during high-demand ticket drops.
